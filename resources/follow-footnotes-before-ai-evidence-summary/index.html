Follow a Business Book Footnote Before Asking AI to Summarize Its Evidence

A footnote is a route toward evidence, not the evidence in full. A business book may point to an article, report, interview or another book, while the reader sees only a short reference at the bottom of a page or in an endnote section. An AI assistant can help organize that route, but it should not turn an unread reference into a verified finding or a remembered title into a fabricated quotation.

This guide develops a practical workflow for following a note from a passage to a specific source and, when available, to the relevant source material. All six examples are original fictional teaching cases. They contain invented source labels, titles, note numbers and dates. They are not quotations from any book, descriptions of a manuscript, actual search results or observed model responses. The purpose is to make source relationships and unresolved steps visible before asking AI to explain evidence.

Separate the passage, note, reference and retrieved material

Begin with the passage you are trying to understand. Record its location in the edition you are actually reading and state the question in your own words. Then identify the attached note marker and the corresponding note text. A note may supply a citation, commentary or several references. Keep those components separate instead of copying a nearby title and assuming that it supports every sentence in the surrounding paragraph.

Next identify the bibliographic reference. This is the description that helps distinguish the intended work: an author, title, edition, publication details and any locator or identifier the source provides. A reference can be sufficiently complete to search for a work without containing the material needed to evaluate the claim. Finding a matching title is therefore a different step from reading the relevant passage in that work.

Finally distinguish the material you actually retrieved. It might be a metadata record, an abstract, a full article, a selected page or an authorized excerpt. These objects support different statements about what has been inspected. A metadata record can help identify a publication; it does not automatically give you the argument on a cited page. A full-text file can still leave the relevant location unread.

Harvard's Guide to Using Sources explains the basic relationship between numbered note markers and footnotes or endnotes, and lists bibliographic details that may appear in them. Use that as reading context, not as a universal description of every business book's format. Follow the actual edition's organization and conventions. This guide does not certify a citation style or supply a replacement bibliography for an unseen book.

Give the assistant a bounded extraction task first

Ask AI to organize only the note and reference information you have supplied. A useful instruction is to separate the passage locator, note marker, note text, candidate source and missing fields, while preserving original spellings. Do not ask it to fill gaps from memory. If it proposes a candidate source, require a clear distinction between a candidate and an established match.

This extraction task is narrower than evidence evaluation. It can help you notice an omitted page number or a shortened title before you start looking for the source. It should not generate a summary of the cited work unless relevant source material is actually available in the task. A confident paragraph based only on a citation can conceal that the work itself has not been read.

Keep your own paraphrase separate from supplied source text. If you write a question about a passage, label it as your question. If you supply an excerpt, retain its edition and locator and follow the applicable sharing permissions. The assistant should not present your paraphrase as a direct quotation or attribute a proposed interpretation to an author without textual support.

A practical output can use ordinary fields such as provided, candidate, not supplied and not inspected. Define those states before reviewing the result. They describe the evidence available in this task, not whether a source is globally unavailable or whether a cited claim is false. A failed lookup or missing excerpt leaves a specific step unresolved; it does not settle the truth of the underlying proposition.

Case A: one note can point to more than one source

The first fictional example has a passage label EX-P1 and an attached note number 12. The authored note contains two reference labels, EX-S1 and EX-S2. The exercise supplies no statement assigning a particular clause in EX-P1 to either reference. There is one passage label, one note marker and two candidate source links. That structure alone does not identify which source supports which part of the passage.

An assistant can map the supplied relationships as EX-P1 to note 12, then note 12 to EX-S1 and EX-S2. It should not draw an additional link from every clause to both sources unless the supplied text justifies that interpretation. A note containing two references is not automatically two independent confirmations of every nearby assertion.

For a real reading task, inspect the placement of the note marker and the complete note text. Look for language that identifies what each reference contributes. One source might be background while another supplies a specific result; the note might also include an author's comment. Those are possibilities to investigate, not facts established by this fictional structure.

A bounded prompt can ask the assistant to list the candidate source relationships and then identify the missing attribution question. The useful output is a clear next reading step: determine the role of each reference in the passage. It should not say the book has two supporting studies or that the evidence has been corroborated, because the case provides neither source content nor a study-independence analysis.

Case B: a shortened reference needs its earlier context

The second authored case supplies note 19 as a full reference to fictional source EX-S7, with author label Mira Vale, title Harbor Methods and publication year 2012. Note 20 contains the shortened form Vale, Harbor Methods, page 27. Under the explicitly supplied mapping for this exercise, note 20 refers to EX-S7 and adds a page locator. The full reference and the shortened note play different roles.

Now consider an alternate excerpt containing only note 20. That excerpt lacks note 19 and the exercise's full-reference mapping. A reader can retain the author label, shortened title and page 27, but cannot recover every missing publication field from those characters alone. A plausible source found elsewhere remains a candidate until the necessary matching information is established.

Do not have an assistant invent a publisher, subtitle, edition or identifier to make the citation look complete. Even a real author can have multiple works or editions with similar titles. A shortened reference relies on context in the actual document; removing that context changes what the excerpt supports. Ask for the relevant earlier note or bibliography entry when it is available rather than guessing the missing fields.

Harvard's guidance discusses complete and shortened citations and the move toward shortened references rather than relying on ibid. This guide does not prescribe a style change for a book you are reading. The practical lesson is to preserve the contextual reference that makes the shortened form interpretable. If an unfamiliar convention appears, consult that edition's notes and relevant citation guidance before assigning a source.

Case C: printed page numbers and file positions can differ

The third fictional case supplies a digital file with four front-matter images before printed page 1. Under this deliberately declared consecutive mapping, printed page 27 appears at one-based image position 31. The zero-based index for that same image is 30. These three labels identify the same authored position using different coordinate systems; the mapping was supplied for the exercise rather than inferred from a real PDF.

The calculation is four plus 27 equals 31, and 31 minus one equals 30. It does not establish that every file has a fixed offset or that a particular book's page 27 is located there. Real files may include inserted plates, omitted pages, alternate page labels or other structures. Use the actual file's labels and visible page information to establish the correspondence you need.

For a reading note, keep the printed locator from the citation and the file locator you used to reach it in separate fields. Do not replace one with the other without explanation. Someone using a different edition or viewer may need the printed page, while someone reproducing your file inspection may need the image position or index. Both can be useful if their definitions are explicit.

An assistant organizing your notes should preserve the distinction between a cited locator and a verified location in an inspected file. It can reproduce the arithmetic for the fictional mapping. It cannot claim to have opened a page, read its text or confirmed a quotation merely because it calculated an index. Retrieval, navigation and reading are separate evidentiary steps.

Case D: publication dates are not event dates

The fourth authored example assigns three dates different roles. A fictional reference has an original publication year of 2005 and a reprint year of 2018. A separate note mentions an event-year label of 1990. The differences between these year labels are 13 years from publication to reprint and 15 years from event label to original publication. These are year-label calculations, not exact elapsed durations between known calendar dates.

A reprint date does not establish when the event occurred. An original publication date does not establish when a study collected its data. The exercise gives only the three declared labels. If a reader needs an event chronology, a data-collection period or a version history, those questions require the relevant source details rather than a subtraction using whatever years appear nearby.

Ask an assistant to preserve date roles in its extraction. A column called year is too ambiguous when a note can mention an event, publication, revision or access date. Label the role alongside the value and leave the role unresolved when the source does not establish it. This prevents a neat timeline from being assembled out of dates that describe different things.

For a real book-reading question, identify which edition the note belongs to before comparing it with a later source version. The version you find today may differ from the one cited. That does not automatically invalidate the reference, but it means the relationship needs checking. This guide performs no actual publication-history lookup and establishes no revision or event chronology for a real work.

Case E: two appearances do not necessarily mean two studies

The fifth fictional case contains two note appearances, N3 and N9, both explicitly mapped to the same source identifier EX-S9. One appearance includes a publisher-page link label and the other a repository-page link label. The exercise specifies that they refer to the same source object. There are two note appearances and one distinct supplied source identifier, not two independently established studies.

Counting citations or links as independent evidence can exaggerate what a bibliography supplies. A repeated reference can be useful for tracing where an author uses a source, but it does not multiply the source's observations. Conversely, a shared title in an actual search result does not by itself establish that two records are identical. The identity relation in this exercise is explicitly supplied, not discovered from title similarity.

An assistant can report both occurrence count and distinct supplied-source count. It should preserve the two note locations so you can return to each use while avoiding a claim of independent corroboration. If two versions or related publications appear in an actual source chain, determine their relationship from appropriate records and content before combining or separating them in an evidence summary.

This step is especially helpful when a book's argument refers repeatedly to a memorable example. The repeated use may be rhetorically important, but the number of appearances is a different question from the number of underlying observations. A reading note should make that distinction visible without claiming that repeated citation is itself a flaw or that a source's conclusions are therefore wrong.

Case F: matching metadata does not mean the source was read

The final authored case supplies fictional bibliographic metadata for EX-S11: author Mira Vale, title Queue Notebook and publication year 2014. A separate candidate record repeats those three fields, and the exercise explicitly labels the retrieved material metadata only. The fields match literally within the supplied example. The relevant full text and cited passage are not included or inspected.

Crossref's REST API documentation describes a service exposing scholarly metadata deposited by members and trusted sources, including bibliographic information and other fields. It helps explain why metadata can be useful for discovery while remaining a different object from the complete source. This guide reads that documentation only. It does not query an actual work record, resolve a DOI or verify the invented source labels through Crossref.

A summary can say that the supplied metadata fields match and that full-text inspection remains unresolved. It cannot say the source confirms the book's claim, contains a particular quotation or has been professionally reviewed in this task. Those statements would require evidence beyond the metadata match. An abstract, if available in another task, would also need to be identified as an abstract rather than silently treated as the entire work.

Ask the assistant to retain a retrieved-material field and an inspected-material field. A file may have been found but not read, and a record may identify a publication without supplying its pages. Keeping those states distinct helps prevent the assistant from writing past the evidence. The desired outcome is an honest source chain whose unfinished step is visible to the reader.

Move from the reference to a focused source question

Once you identify the intended source, decide what you need to inspect. A broad question such as is this book right is difficult to resolve from a single note. A narrower question might ask whether the cited page defines a term, reports a particular numerical comparison or supports a stated condition. The question determines which material is relevant and what a bounded explanation can say.

Retain the relationship between the book's use of the source and the source's own wording. A book may summarize, interpret or apply a source rather than repeat it verbatim. If both passages are available, ask the assistant to distinguish those roles using the supplied text. Do not request an invented quotation to make an interpretation seem better supported. Exact quotations require exact inspected text and a usable locator.

If you reach a secondary source that itself cites earlier work, extend the chain rather than pretending you have reached the original evidence. Name what you actually read and identify the earlier reference as another step. This guide does not supply a universal rule that an earlier source is always better; it asks you to preserve the path so a reader can evaluate the role of each source in the explanation.

Stop at the evidence boundary when the relevant material is unavailable in the task. Record the specific missing item, such as the full reference, the cited page or a version match. Do not conclude that the source does not exist or is globally inaccessible. A limitation in one search or supplied excerpt says something narrower about what has been established here.

Use an AI prompt that keeps provenance visible

A practical instruction can ask the assistant to produce four linked sections: passage question, supplied note information, candidate source chain and unresolved steps. Tell it to use only supplied text for content attributions and to keep any suggested search separate from established findings. Require it to preserve edition, locator and date roles instead of compressing them into a single citation-like sentence.

For a small exercise, inspect each proposed link manually against the supplied fields. Confirm that the note number matches the passage marker, that a shortened form maps to the intended full reference and that the locator uses the stated coordinate system. These checks concern the source chain. They do not establish that a cited study is methodologically sound or that an author's interpretation is correct.

Keep the result useful for the next reading session. A note saying source not checked is less actionable than a note identifying the exact page or full reference still needed. At the same time, do not turn the worksheet into an endless collection exercise. Follow the reference needed for the current reading question and summarize the boundary reached, then return to the passage with that improved context.

The original cases here can serve as a prompt rehearsal: ask an assistant to organize their fields without inventing content, then inspect the proposed chain. This guide provides no observed assistant outputs or accuracy scores. If you later evaluate an actual model, retain the real output, the scoring rule and the review evidence separately from these teaching examples.

Frequently asked questions

Does a footnote prove that the nearby claim is correct?

A note can point toward relevant sources or commentary, but the reference alone is not a completed evaluation of the claim. Identify what the note refers to, retrieve the relevant material when available and distinguish what was actually inspected from what remains unresolved.

Can AI fill in a shortened reference from a familiar title?

It can suggest a clearly labeled candidate, but missing edition or publication fields should not become established facts from memory. Use the actual earlier note, bibliography or appropriate source record to resolve the match. Preserve uncertainty when the supplied material is incomplete.

Is a PDF image index the same as a cited printed page?

Not automatically. The fictional mapping includes four front-matter images and distinguishes printed page 27, one-based image position 31 and zero-based index 30. Establish the mapping for the actual file instead of applying that offset universally.

Do two links to a source count as independent evidence?

Not by themselves. The authored N3 and N9 appearances both map to EX-S9, producing two occurrences but one supplied source object. An actual independence question needs evidence about the underlying sources and observations, not just a link count.

Does matching Crossref metadata mean the cited passage was verified?

No. Metadata supports discovery and identification questions within its scope. This guide queried no actual work record and read no cited book passage. A matching author, title and year do not establish the content of an unread page.

Are the source titles and note examples quotations from Connor's books?

No. All source labels, titles, note numbers, locators and dates in the six cases are original fictional teaching material. They imply no manuscript access, chapter method, author endorsement, observed model result or professional evidence review.
